## 🚀 Features
- The fetch request now includes `scriptSrc`: the URL the ID5 script (API, API Lite or the Prebid.js external module) was loaded from. It is omitted when the script has no `src` (e.g. inline or bundled).

## 🛠 Maintenance
- The `url` key in `partnerData` is deprecated and kept only for backward compatibility.

## 🐞 Bug fixes
- The Prebid.js external module (`id5PrebidModule.js`) now passes the `provider` param from the Prebid ID5 User ID module config to the ID5 fetch request. Before, it was dropped, so integrations that set both `externalModuleUrl` and `provider` (e.g. Aditude, `aditude_1016`) were reported without a provider.
