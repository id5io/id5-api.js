## 🛠 Maintenance
- Full page URLs are no longer sent in request bodies. The fetch request fields `u`, `tml` and `ref` now carry only the origin (scheme, host and port, e.g. `https://example.com`), with no path, query string or fragment. The canonical URL (`cu`) is no longer sent. This also applies to the API Lite, the Prebid.js external module and the `tml` diagnostics tag.
- Multiplexing instances no longer share their window URL with each other through `postMessage`. Unique windows are now counted using a random per-window identifier.
- Calls to ID5 made with `fetch()` (extensions, events, diagnostics, Prebid analytics) and the sync pixel set `referrerPolicy: 'origin'`, so the `Referer` header carries only the page origin, whatever referrer policy the page uses.
