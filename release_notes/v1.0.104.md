## 🚀 Features
- Prebid enabler: added `createForDefault()`, `createForNamed()` and `createFor()` to configure a chosen Prebid.js instance.
- Prebid enabler: added `buildUserIdConfig()` and `rebuildUserIdConfig()`, which return the ID5 entry of `userSync.userIds` for pages that write their Prebid configuration themselves.
- Prebid enabler: added the `'auto'` value of `refreshOnReconfigure`, now the default. It refreshes the ID5 submodule after `reconfigureUserIdModule()` only where the refresh leads to a fetch.

## 🛠 Maintenance
- Prebid enabler: `setup()` is deprecated. Use `createForDefault()`, `createForNamed()` or `createFor()`.

## 🐛 Bug Fixes
- Prebid enabler: `reconfigureUserIdModule()` refuses a call naming another partner than the one the page configures.
- A cached response that carries no signature is used as a complete one.
